# QW Solutions Website

A static, responsive business website built with HTML, CSS and JavaScript.

## Hosting on GitHub Pages
Upload the contents of this folder to a GitHub repository, then enable:
Settings → Pages → Deploy from a branch → main → /(root)

## Contact form
The current form uses `mailto:` and opens the visitor's email application. For server-side form delivery later, replace the submit handler in `script.js` with a backend or form service.

## Main files
- `index.html` — website content
- `styles.css` — design and responsive layout
- `script.js` — navigation, animations and quote form
- `assets/images/qws-logo.png` — local logo asset
